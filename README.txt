CARA MENJALANKAN PROYEK SECARA LOKAL
--------------------------------------------------------------------
1. Buka folder proyek di Visual Studio Code.
2. Karena proyek dibangun menggunakan arsitektur Pure Code (HTML, CSS, JS),

3. Untuk kompilasi ulang Tailwind CSS v4 (opsional), jalankan perintah:
   $ npm install
   $ npm run watch
