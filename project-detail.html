01. Aplikasi Pencatatan Tugas Kuliah

Studi kasus pengembangan perangkat lunak desktop lokal berbasis Windows untuk membantu mahasiswa mengelola beban tugas akademis, tenggat waktu, dan pengingat jadwal secara offline dengan performa eksekusi instan.

KATEGORI Desktop App
PERAN Lead Developer
PLATFORM Windows OS
STATUS Completed

Latar Belakang

Banyak mahasiswa mengalami kesulitan dalam melacak puluhan tugas dari berbagai mata kuliah yang memiliki tenggat waktu saling berdekatan. Aplikasi pencatat berbasis web sering kali membutuhkan koneksi internet dan memakan memori RAM yang cukup besar. Proyek ini dirancang sebagai solusi lokal yang ringan, cepat, dan bekerja sepenuhnya secara offline dengan SQLite.

Fitur Unggulan

  • • Manajemen Terstruktur: Filter status pengerjaan dan prioritas tenggat waktu otomatis.
  • • Offline SQLite: Eksekusi query lokal di bawah 50ms tanpa jeda loading.
  • • UI Bersih JavaFX: Desain antarmuka grafis yang intuitif dan nyaman untuk harian.

03. Perancangan Basis Data Keuangan Pribadi

Studi kasus perancangan dan pemodelan skema basis data relasional untuk mencatat, mengelompokkan, dan memetakan laporan keuangan pribadi dengan efisiensi tinggi tanpa redundansi data.

KATEGORI Database Project
PERAN Database Designer
PLATFORM MySQL / MariaDB
STATUS Completed

Latar Belakang

Pencatatan keuangan manual atau spreadsheet sering menyebabkan duplikasi data dan kesalahan perhitungan arus kas. Proyek ini menyelesaikan masalah tersebut melalui pendekatan RDBMS dengan normalisasi 1NF hingga 3NF yang menjamin integritas data transaksi dan mempercepat query statistik.

Fitur Unggulan

  • • Normalisasi 3NF: Tabel dipisahkan logis untuk menghilangkan redundansi data.
  • • Foreign Key Integrity: Relasi ketat memastikan tidak ada transaksi yatim.
  • • Optimasi Indexing: Query total pengeluaran dieksekusi dengan sangat cepat.
